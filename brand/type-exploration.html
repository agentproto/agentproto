agentproto — typography exploration, 2026-08-07. Logotype/mono is locked (see README.md); this compares 3 directions for headings/body/UI copy. All system-font-only, zero webfont cost.
Option A — all mono
Wordmark's stack (ui-monospace / SF Mono / Menlo) reused for everything. Fully terminal-native.
Run any agent, from any CLI.
agentproto is the open protocol that lets Claude Code, hermes, and codex talk to the same daemon.

A session survives a restart. A worktree isolates a parallel agent. A policy gates a commit on a green test run — durable supervision, not a chat window you have to babysit.

❯ agentproto sessions start --adapter claude-code
Option B — mono chrome + system sans
Mono stays for the logo/code/CLI only. Headings + body switch to system sans (-apple-system / Segoe UI / Roboto) — the standard dev-tool docs pattern.
