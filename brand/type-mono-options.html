agentproto — monospace typeface options, 2026-08-07. All-mono direction locked (see design.md); this compares which mono. Real embedded fonts (Google Fonts) so it renders the same for everyone, unlike the OS-dependent system stack.
Baseline — system stack (current)
ui-monospace / SF Mono / Menlo / Cascadia Mono — whatever the OS has. Free, zero load, but renders differently per platform.
Run any agent, from any CLI.
agentproto is the open protocol that lets Claude Code, hermes, and codex talk to the same daemon.

A session survives a restart. A worktree isolates a parallel agent. A policy gates a commit on a green test run — durable supervision, not a chat window you have to babysit.

❯ agentproto sessions start --adapter claude-code

Option 1 — JetBrains Mono
Free, OFL-licensed. The most widely adopted dev-tool mono today (VS Code, Linear, countless CLIs). Tall x-height, distinct 0/O and l/1, ligatures available. Safe, proven, slightly "default choice" at this point.

Option 2 — IBM Plex Mono
Free, OFL-licensed. Slightly more geometric/neutral than JetBrains, narrower — reads a bit more "corporate infra tool" than "editor font." Pairs cleanly with Plex Sans/Serif if this system ever needs a non-mono fallback.

Option 3 — Space Mono
Free, OFL-licensed. Quirky/retro-terminal character (rounder terminals, distinct italics) — most "brand personality," least neutral. Great for the wordmark/marketing titles, arguably too loud for dense docs body copy at length.
